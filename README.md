# Glance Widgets API SDK

SDKs for generating Glance Widgets API responses

| SDK | Install |
| --- | --- |
| [Go](sdks/go/) | <code>go get github.com/GlanceWidgets/glance-widgets-api-sdk/sdks/go@v1.0.0</code> |
| [PHP](sdks/php/) | <code>composer require glancewidgets/api-sdk:1.0.0</code> |
| [C++](sdks/cpp/) | Download <code>glance-widgets-cpp-1.0.0.tar.gz</code> from [Releases](https://github.com/GlanceWidgets/glance-widgets-api-sdk/releases). |

See the [protocol reference](spec/protocol-facts.md) and [shared test fixtures](spec/golden/).
